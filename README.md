# KAP-Survey - استبيان المعرفة والمواقف والممارسات

A comprehensive Knowledge, Attitudes, and Practices (KAP) survey application with a modern, bilingual (Arabic/English) user interface.

## 🌟 Features

- **Bilingual Support**: Arabic (RTL) and English interface
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Beautiful gradient design with smooth animations
- **Form Validation**: Real-time validation with user-friendly error messages
- **Auto-save**: Automatically saves draft responses to prevent data loss
- **Local Storage**: Stores completed surveys locally for data persistence
- **Accessibility**: Designed with accessibility best practices

## 📋 Survey Sections

The survey consists of four main sections:

1. **Knowledge (المعرفة)**: Assesses the user's understanding and awareness
2. **Attitudes (المواقف)**: Evaluates opinions and perceptions
3. **Practices (الممارسات)**: Measures actual behaviors and actions
4. **Demographics (معلومات عامة)**: Collects basic demographic information

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- No additional dependencies or installations required

### Usage

1. Open `index.html` in your web browser
2. Fill out the survey form
3. Click "إرسال الاستبيان" (Submit Survey) to submit
4. Your responses will be saved locally

### For Developers

The project consists of three main files:

- `index.html`: The main HTML structure
- `styles.css`: All styling and responsive design
- `script.js`: Form validation, submission handling, and interactivity

## 🎨 Customization

You can easily customize the survey by:

- Modifying questions in `index.html`
- Adjusting colors and styles in `styles.css`
- Updating validation logic in `script.js`

## 💾 Data Storage

Survey responses are stored in the browser's localStorage. To view stored data:

1. Open browser developer tools (F12)
2. Go to the Application/Storage tab
3. Look for `kapSurveys` in localStorage
