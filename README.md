# 🏗️ تطبيق متابعة الأعمال

تطبيق ويب شامل لمتابعة وإدارة المشاريع الإنشائية والأعمال

## ✨ المميزات

- 🖥️ **يعمل على سيرفر محلي** - يعمل على جهاز الكمبيوتر الخاص بك
- 👥 **نظام مستخدمين متكامل** - إنشاء مستخدمين بصلاحيات مختلفة:
  - **مالك**: جميع الصلاحيات (إضافة، تعديل، حذف، إدارة المستخدمين)
  - **محرر**: يمكنه إضافة وتعديل المشاريع والمهام
  - **مشاهد**: يمكنه المشاهدة فقط
- 📊 **إدارة المشاريع** - متابعة المشاريع الإنشائية بسهولة
- ✅ **إدارة المهام** - تنظيم المهام مع الأولويات والتواريخ
- 📈 **لوحة تحكم** - إحصائيات وتقارير شاملة
- 🌐 **الوصول من الشبكة** - يمكن الوصول للتطبيق من أي جهاز على نفس الشبكة
- 🔒 **آمن** - نظام مصادقة محمي وتشفير كلمات المرور

## 📋 المتطلبات

- Node.js (الإصدار 14 أو أحدث)
- npm (يأتي مع Node.js)

## 🚀 التثبيت والتشغيل

### الطريقة السريعة (أمر واحد فقط!)

#### لمستخدمي Windows:
```bash
start.bat
```

#### لمستخدمي Linux/Mac:
```bash
./start.sh
```

### التثبيت اليدوي

1. **تثبيت المتطلبات:**
```bash
npm install
```

2. **تشغيل التطبيق:**
```bash
npm start
```

## 📱 الوصول للتطبيق

بعد تشغيل التطبيق، سيظهر لك:

```
🚀 تطبيق متابعة الأعمال يعمل الآن!
📍 الوصول المحلي: http://localhost:3000
📍 الوصول من الشبكة: http://192.168.x.x:3000
```

### الوصول من أجهزة أخرى على نفس الشبكة:

1. افتح المتصفح على أي جهاز آخر على نفس الشبكة
2. اكتب عنوان IP الذي ظهر في الرسالة (مثال: `http://192.168.1.100:3000`)

## 🔑 بيانات الدخول الافتراضية

عند أول تشغيل، يتم إنشاء حساب مدير افتراضي:

```
اسم المستخدم: admin
كلمة المرور: admin123
```

⚠️ **مهم:** يُنصح بتغيير كلمة المرور بعد أول تسجيل دخول

## 📖 كيفية الاستخدام

### 1. تسجيل الدخول
- استخدم بيانات الدخول الافتراضية أو حسابك الخاص

### 2. إدارة المستخدمين (للمالك فقط)
- اذهب إلى تبويب "المستخدمين"
- اضغط "إضافة مستخدم"
- أدخل البيانات واختر الدور المناسب

### 3. إضافة مشروع
- اذهب إلى تبويب "المشاريع"
- اضغط "إضافة مشروع"
- أدخل تفاصيل المشروع (الاسم، الوصف، الموقع، التواريخ)

### 4. إضافة مهام
- اذهب إلى تبويب "المهام"
- اضغط "إضافة مهمة"
- اختر المشروع واملأ تفاصيل المهمة
- يمكنك تعيين المهمة لمستخدم معين

### 5. متابعة التقدم
- لوحة التحكم تعرض إحصائيات شاملة
- يمكنك تحديث حالة المشاريع والمهام
- تصفية المهام حسب الحالة والأولوية

## 🔧 إعدادات إضافية

### تغيير المنفذ (Port)
يمكنك تغيير المنفذ من 3000 إلى أي رقم آخر:

**Windows:**
```bash
set PORT=8080 && npm start
```

**Linux/Mac:**
```bash
PORT=8080 npm start
```

### الوصول من شبكات مختلفة
لكي يصل المستخدمون من شبكات مختلفة:
1. افتح المنفذ 3000 في جدار الحماية
2. استخدم عنوان IP العام للسيرفر
3. يمكنك استخدام خدمات مثل ngrok للوصول الخارجي

## 🔒 أمان التطبيق

⚠️ **ملاحظات أمان مهمة:**

1. **كلمة المرور الافتراضية**: يتم إنشاء كلمة مرور عشوائية آمنة عند أول تشغيل
2. **الاتصال الآمن**: للاستخدام عبر الإنترنت، يُنصح بشدة باستخدام HTTPS
3. **الاستخدام المحلي**: التطبيق مصمم للاستخدام على شبكة محلية موثوقة
4. **تغيير كلمة المرور**: قم بتغيير كلمة مرور المدير بعد أول تسجيل دخول
5. **النسخ الاحتياطي**: قم بعمل نسخة احتياطية من ملف `worktracker.db` بانتظام

## 💾 البيانات

- يتم حفظ جميع البيانات في ملف قاعدة بيانات SQLite محلي (`worktracker.db`)
- يتم إنشاء القاعدة تلقائياً عند أول تشغيل
- البيانات محفوظة حتى بعد إغلاق التطبيق

## 🆘 حل المشاكل

### المشكلة: "المنفذ 3000 قيد الاستخدام"
**الحل:** استخدم منفذ مختلف كما هو موضح في قسم الإعدادات

### المشكلة: "لا يمكن الوصول من أجهزة أخرى"
**الحل:** 
1. تأكد أن الأجهزة على نفس الشبكة
2. تأكد من إيقاف جدار الحماية أو فتح المنفذ
3. استخدم عنوان IP الصحيح (يظهر عند تشغيل التطبيق)

### المشكلة: "خطأ في تثبيت المتطلبات"
**الحل:**
1. تأكد من تثبيت Node.js بشكل صحيح
2. جرب حذف مجلد `node_modules` وإعادة تشغيل `npm install`
3. تأكد من اتصالك بالإنترنت
